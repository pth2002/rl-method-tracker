RL post-training for language models · January 2025 to June 2026

1,598 RL training methods on arXiv. 37 reached framework code.

Each dot is one paper that proposed a general RL training method, stacked by the month of its first arXiv version. A dot is green when the method reached the main branch of at least one of seven open-source frameworks. Every date comes from the frameworks' own commit histories.

Methods by training failure

Pick the failure you see in training. Each cell links to the line of code that offers the method in that framework, at the snapshot commit. The tracker lists implementations and does not test whether a method helps.

Latest landings

A landing is the first commit that put a method on a framework's main branch. Days run from the method's source to that commit. The list grows with the weekly update.

    Seven frameworks

    How many methods each framework took in, how fast, and what happened to public proposals for the methods no framework included. The guide to each framework lists its contribution rules and the concerns its reviewers raised.

    Methods counts landings of catalog methods with a source from 2025 or later, and first anywhere counts the methods with their first landing there. Median days run from the source to the landing and leave out upper bounds. A landing pull request counts as opened by a prior merger when its author had merged a pull request in the framework before. Declined proposals include those redirected elsewhere, and lapsed proposals were closed as inactive. ROLL publishes code in bulk releases without pull requests.

    Reproduce

    git clone https://github.com/pth2002/rl-method-tracker
cd rl-method-tracker
git checkout v1.0
pip install -r requirements.txt
python tools/reproduce_report.py --pdf

    The last command checks the frozen inputs and rebuilds every number, table and figure without network access. The PDF step needs pdflatex.
